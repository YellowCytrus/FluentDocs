## B-01. Автоперенос формул (S4) — решено

Typst 0.14.2 не разрывает `math.equation` автоматически и не предупреждает о
переполнении: формула из 40 слагаемых вышла за поля (853.7 pt при ширине
страницы 595.3 pt).

**Решение владельца:** принят fallback — ручной разрыв формулы `\` в Markdown;
помощник `fd.eq-break` не делаем. Прототип оставлен как подтверждение механизма.

## B-02. Версии Pandoc — решено

Сервер был на Pandoc 3.11, `pandoc-wasm` 1.0.1 — на 3.9. Разница: сервер 3.11
добавлял `alt: "..."` в `#figure(image(...))`.

**Решение владельца:** сервер фиксируется на Pandoc 3.9, как в `pandoc-wasm`.
`Dockerfile` содержит `ARG PANDOC_VERSION=3.9`; `tests/test_versions.py` падает,
если `pandoc --version` не `pandoc 3.9`. Выходы S5 сервера и wasm на 3.9
совпадают байт в байт.

## B-03. Раскладка документов — решено

**Решение владельца:** принята фактическая раскладка `docs/`; `AGENTS.md`
обновлён: план v2 — `docs/sprint/FluentDocs_SFU_rules_plan_v2.md`,

## B-04. Тесты без Postgres — исправлено, GitHub CI не прогонялся

`tests/conftest.py` больше не пропускает весь набор: фикстура `db_available`
только проверяет доступность Postgres, а `pytest.skip` вызывается лишь в
DB-фикстурах (`test_engine`). Golden-тест и тест версий выполняются без БД.

Проверки без Postgres: `tests/test_typst_golden.py -m integration` — 8 passed;
`tests/ -m "not integration"` — DB-тесты skipped, остальные passed (см. отчёт).
Прогон GitHub Actions в этом окружении недоступен; в workflow добавлена установка
Pandoc 3.9.

## B-05. Ограничение S10 — решено (принято)

Снятие номера по тексту компенсирует счётчик, но подразделы ненумерованного
заголовка получают номер `0.1`. Владелец принял ограничение: для
«Введения»/«Заключения» подразделов по СТУ нет.

## B-06. Typst CLI и `typst.ts` — не возникает

На сервере Typst CLI 0.14.2 (`Dockerfile`), компилятор в `typst.ts` 0.7.0-rc2 —
тоже Typst 0.14.2 (проверено `frontend/scripts/typst-ts-version.mjs` через
`#sys.version`). Локальная среда также переведена на Typst 0.14.2. Версии
совпадают, блокер не заводится. Данные — в `docs/sprint/VERSIONS.md`.
