## B-01. Автоперенос формул (S4) — решено

Typst 0.14.2 не разрывает `math.equation` автоматически и не предупреждает о
переполнении: формула из 40 слагаемых вышла за поля (853.7 pt при ширине
страницы 595.3 pt).

**Решение владельца:** принят fallback — ручной разрыв формулы `\` в Markdown;
помощник `fd.eq-break` не делаем. Прототип оставлен как подтверждение механизма.

## B-02. Версии Pandoc — решено

Сервер был на Pandoc 3.11, `pandoc-wasm` 1.0.1 — на 3.9. Разница: сервер 3.11
добавлял `alt: "..."` в `#figure(image(...))`.

**Решение владельца:** сервер фиксируется на Pandoc 3.9, как в `pandoc-wasm`.
`Dockerfile` содержит `ARG PANDOC_VERSION=3.9`; `tests/test_versions.py` падает,
если `pandoc --version` не `pandoc 3.9`. Выходы S5 сервера и wasm на 3.9
совпадают байт в байт.

## B-04. Тесты без Postgres — решено

`tests/conftest.py` больше не пропускает весь набор: фикстура `db_available`
только проверяет доступность Postgres, а `pytest.skip` вызывается лишь в
DB-фикстурах (`test_engine`). Golden-тест и тест версий выполняются без БД.

CI: `test` — 133 passed, 139 deselected; `integration` — 139 passed,
133 deselected; `lint` — success.

## B-05. Ограничение S10 — снято в G3a

Старый прототип компенсировал счётчик и давал подразделам ненумерованного
заголовка номер `0.1`. В G3a заголовки пересобираются одним проходом по телу;
`numbering: none` не сдвигает счётчик, подразделы получают номер относительно
предыдущего раздела. См. `SPIKES.md` S10 и `tests/test_g3a_structural.py`.

## B-06. Typst CLI и `typst.ts` — не возникает

На сервере Typst CLI 0.14.2 (`Dockerfile`), компилятор в `typst.ts` 0.7.0-rc2 —
тоже Typst 0.14.2 (проверено `frontend/scripts/typst-ts-version.mjs` через
`#sys.version`). Локальная среда также переведена на Typst 0.14.2. Версии
совпадают, блокер не заводится. Данные — в `docs/sprint/VERSIONS.md`.


## B-07. Скорость перерисовки в реальном браузере — решено, исправление отложено

Решение владельца: сейчас механизм не исправлять. Порог S8 для документа
100+ страниц понимать как «видимая страница обновилась за ≤ 2 с», а не как
«перерисованы все 114 страниц».

Замер G2b: Playwright + Chromium (headless), реальный редактор `/`,
профиль по умолчанию, документ 900 абзацев → **114 страниц**. Первая отрисовка
первой страницы определялась по первому тёмному `fill` в canvas превью;
`toDataURL` не использовался. Три прогона:

| Этап | Холодный старт | Правка первой страницы |
|---|---:|---:|
| Компиляция `typst.ts` (остаток `$typst.canvas`) | 501–554 мс | **339–365 мс** |
| Получение страниц (`retrieve`) | 31–40 мс | 37–47 мс |
| Отрисовка всех canvas (`display`) | 3 448–3 853 мс | 3 388–3 549 мс |
| Текстовый слой | 17–21 мс | 78–85 мс |
| Итого `$typst.canvas` | 3 997–4 465 мс | 3 842–4 030 мс |
| **Первая видимая страница** | **2 039–2 145 мс** | **1 668–1 750 мс** |
| Пик JS heap (rAF-выборка) | 117.5–123.9 МБ | 71.0–74.1 МБ |
| JS heap после отрисовки (CDP) | 42.5–45.9 МБ | 43.1–54.8 МБ |

Тёплая правка укладывается в новый порог ≤ 2 с (1.67–1.75 с), холодный старт
даёт 2.04–2.15 с. Полная отрисовка всех 114 страниц остаётся 3.4–3.9 с, потому
что `typst.ts` рисует все canvas, а не только видимые. Виртуализация/ленивая
отрисовка страниц — задача после G2c, отдельно от G2b.

## B-08. Трактовка `around.collapse = none` — решено

Решение владельца: режим `none` удалить. Остаются два режима:

- `max` — вставка заменяет штатный интервал элемента (слабый `v`);
- `sum` — вставка добавляется к штатному интервалу (жёсткий `v`).

Старые значения `collapse: "none"` при чтении JSONB мигрируют в
`collapse: "max"` с пустыми `before`/`after`, чтобы поведение не менялось.
`blank.count = 0` — осознанный нулевой интервал: при `max` даёт `v(0)`,
при `sum` ничего не добавляет. `PROGRESS.md` и `REGISTRY_SPEC.md` обновлены.

## B-09. Автозамер коэффициента высоты строки — открыт

Для известных шрифтов коэффициент естественной высоты строки лежит в таблице
реестра (`Libertinus Serif` — 1.308, `PT Astra Serif` — 1.312, замер S9).
Для нового шрифта вне таблицы пользователь вводит `document.line_height_em`
вручную; автозамер при загрузке шрифта не делается. Это сознательное упрощение
G2b. Если понадобится автозамер, его нужно проектировать отдельно: замер
метрик шрифта в браузере и на сервере должен давать один коэффициент.
