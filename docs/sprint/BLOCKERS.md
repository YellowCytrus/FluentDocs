# Блокеры и расхождения G0

## B-01. Автоперенос формул (S4)

Typst 0.15.1 не разрывает `math.equation` автоматически и не предупреждает о
переполнении: формула из 40 слагаемых вышла за поля (853.7 pt при ширине
страницы 595.3 pt). Ручной разрыв `\` и помощник `eq-break` работают.

Нужно решение владельца: принять fallback «ручной разрыв + помощник `fd.eq-break`»
для G5 или искать другой механизм (например, разбиение формулы на несколько
`math.equation` на уровне Markdown/UI).

## B-02. Версии Pandoc: сервер 3.11, `pandoc-wasm` 3.9

`pandoc --version` в окружении — 3.11. Пакет `pandoc-wasm` 1.0.1
(`frontend/package.json`) содержит Pandoc 3.9 (`pandoc-version.txt`).

Разница в выводе для S5: сервер добавляет `alt: "..."` в `#figure(image(...))`,
wasm — нет. Остальной вывод совпал.

Это блокирует требование «версии должны совпадать» и тест паритета
превью/PDF на G1. Нужно решение: обновить/заменить `pandoc-wasm` до 3.11,
зафиксировать сервер на 3.9 или нормализовать различия в тесте паритета.

## B-04. Локальная проверка CI и тестов

В окружении нет Postgres (нет `postgres`, `pg_isready`, Docker daemon),
поэтому `tests/conftest.py` пропускает весь набор: `51 skipped` (не integration)
и `8 skipped` (golden). Фронтенд: `5 passed`. Ruff в `.venv` отсутствует.

«CI зелёный» по факту не подтверждён локально. Нужен прогон GitHub Actions
или доступный Postgres.

## B-05. Ограничение S10

Снятие номера по тексту компенсирует счётчик, но подразделы ненумерованного
заголовка получают номер `0.1`. Для «Введения»/«Заключения» подразделов по СТУ
нет, поэтому принято как рабочее ограничение. Если структурная сущность с
подразделами потребуется, нужен отдельный механизм.
