# Решения владельца по UX (29.10.2026)

Файл читают агенты перед G3. Источник — ответы владельца на `UX_questions.md`.

## Приняты

1. **Столкновение вставок.** Когда `after` предыдущего элемента встречается с `before` текущего, у текущего элемента выбирается политика (можно по виду предыдущего элемента): оставить вставку предыдущего, оставить свою, оставить обе, убрать обе («аннигиляция»). «Оставить большую» не нужна. По умолчанию — «оставить обе» (решение 29.10.2026). Пример по СТУ: после заголовка пустая строка, перед подписью таблицы пустая строка — одна из них убирается, остаётся одна. Подробности — AGENTS.md 5.1, ворота G2d.
2. **Пустая строка** — именно строка текста (как нажатие Enter в абзаце), её межстрочный интервал задаётся в самой вставке. Вставкам нужно переопределение шрифта.
3. **Структурные элементы** (введение, заключение, приложения…) — список правил «заголовок содержит слово X → оформить так». Помечены как бета. Формат записи заголовка пока такой: `# Приложение Название приложения`. Нумерация: без номера / продолжать общий счётчик / свой счётчик с шаблоном; приложение — пресет своего счётчика.
4. **Приложения:**
   - вывод в одну строку: «ПРИЛОЖЕНИЕ А. Название приложения»; перенос только если не влезает по ширине;
   - буква присваивается автоматически;
   - когда буквы кончились — только **удваивать** (АА, АБ…); после исчерпания удвоения (ЯЯ) те же буквы продолжаются в тройном сочетании (ААА, ААБ…), чтобы `start` до 999 и длинные серии не роняли компиляцию; режимов «остановиться» и «латинские буквы» нет;
   - алфавит «Цифры» (`arabic`) — это 1-based десятичное число: 1, 2, …, 999, а не 0-based цифры;
   - будущий UX (не в спринте): пользователь вводит образец заголовка целиком, программа просит выделить служебное слово, номер и название, и по образцу строит правило.
5. **Нумерация и подписи рисунков/таблиц:** счётчик по главам (1.1, 1.2, 2.1); в приложении вместо номера главы — буква; подпись таблицы — по левой границе, подпись рисунка — по центру; у рисунков и таблиц отдельные шаблоны и отдельные счётчики.
6. **Формулы:** не трогаем (нумерация, подпись, «где…», ссылки). Подпись формулы через двоеточие откладывается.
7. **Списки:** первая строка пункта с отступом, остальные от левого поля (как в абзаце). Опция с двумя значениями: «к левому полю» (по умолчанию) и «по тексту первой строки» (висячий отступ).
8. **Межстрочный интервал** — множитель, а не мм. «1,5» = 1,5 естественной высоты строки выбранного шрифта; визуально близко к Word. Единицы измерения: минимум, почти без выбора у полей; размеры макета — мм с единым переключателем мм/см/дюймы; типографика — пункты и множитель/em.
9. **Оглавление:** глубина; отступ подзаголовков в двух режимах — одно значение шага в мм (отступ = (уровень − 1) × значение) или список мм по уровням; регистр/жирность/шрифт записи из правила; заполнитель не настраивается. Правило «не выводить оглавление» по числу страниц и кнопка «Показать принудительно» в окне редактора, которая есть только когда оглавление скрыто правилом. Группировка приложений одной строкой без подзаголовков — опция, по умолчанию включена.
10. **Таблицы:** границы справа/слева/снизу, двойная линия под шапкой, повтор шапки. Объединения ячеек в этом спринте нет.
11. **Нумерация страниц:** опции из G2c остаются. Идея: элемент «номер страницы» в шаблонных страницах canvas — в бэклог.
12. **Реферат** — отложен целиком.
13. **Рисунки:** по умолчанию вписывать по ширине текста.
14. **Заголовки:** связь со следующим текстом (заголовок не остаётся один внизу страницы) — по умолчанию работает без выбора; нумеруются все уровни, шаблон нумерации и выбор нумеруемых уровней — в настройках (есть).
15. **Профили:** новые профили создаются на основе профиля «СТУ СФУ».

## Открыто (владелец ответит, когда понадобится)

- Оглавление: скрывать при малом числе страниц (≤ N) — предположение, подтвердить.
